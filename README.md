# Portezuelo Care Routes

Actúa como un Desarrollador Full-Stack y Diseñador UI/UX y construye el front-end en React.js y Tailwind CSS de un Panel Web de coordinación para el sistema logístico de atención domiciliaria del CESFAM de Portezuelo, utilizando un diseño minimalista en tonos greige que incluya un menú lateral y un área principal con: un Dashboard de KPIs, un Módulo de Integración simulado para importar datos desde Rayen, un mapa interactivo para georreferenciación rural, un planificador diario para Optimización Logística con Google OR-Tools y listas drag-and-drop, una tabla de supervisión en tiempo real, y un módulo de Auditoría para la trazabilidad de cierres de visita manuales y automáticos por GPS.
